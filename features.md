# HomeBase Features

## Portfolio Dashboard

-   Portfolio health
-   Total portfolio value
-   Total equity
-   Monthly cash flow
-   Occupancy rate
-   Loan, maintenance, insurance, and tax alerts

## Property Details

### Ownership

-   Ownership entity
-   Owners and percentages
-   Formation docs
-   Operating agreement
-   EIN/Tax docs

### Acquisition

-   Purchase price
-   Rehab cost (Buildertrend sync optional)
-   Total project cost
-   Current market value
-   Equity = Current Market Value - Total Project Cost

### Rental

-   Lease is source of truth
-   Monthly/Gross/Net rent
-   Management fees
-   Lease-up fee
-   Other expenses

### Mortgage

-   Escrow or non-escrow
-   Principal, interest, taxes, insurance
-   County tax link
-   Insurance portal link

### Utilities

-   Electric
-   Water/Sewer
-   Gas

## Maintenance

-   Manual entries
-   Future Buildium integration (optional)
-   Recurring maintenance
-   Non-recurring maintenance
-   Vendor, cost, status, invoices, photos
-   Auto-update financial reports

## Financial Automation

-   Cash flow
-   P&L
-   YTD expenses
-   Annual reporting

## AI Email Intelligence

-   Daily summaries
-   Todo generation
-   Detect loans, insurance, leases, maintenance, invoices, taxes,
    contractors, tenants
-   Priority classification
-   Suggested next actions

## AI Asset Manager

-   Market rent analysis
-   Rent recommendations
-   Lease expiration alerts
-   Equity growth
-   Refinance opportunities
-   DSCR
-   ROI
-   Cash-on-cash return
-   Maintenance trends
-   Insurance reminders
-   Tax appeal opportunities
-   Investment score

## Architecture Principles

-   HomeBase owns all core data.
-   Manual entry always works.
-   CSV import supported.
-   Email AI is a primary automation source.
-   Third-party integrations are optional enhancements.
-   Never depend on a single vendor such as Buildium.
